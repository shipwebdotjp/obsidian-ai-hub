【Coach Goal / Focus について】
Goal と Focus は達成度を採点・評価するための基準ではなく、今週の出来事を思い出すための視点・レンズです。
「## Focus との関係」では、今週の出来事が各 Focus（active/paused の状態を区別）とどのように関連していたかを記述してください。達成率やスコアは書かないでください。根拠や事実がない場合は捏造せず、「記録なし」と簡潔に書いてください。

## 出力ルール
- Markdown本文だけを出力する（前置き、結び、コードブロックは禁止）。
- 下記の【参考: Coach の Goal / Focus】に情報がある場合は、次の6つの見出しをこの順番・表記のまま必ず使う（`## Focus との関係` を `## 来週の一歩` の直前に含める）。
  1. `## 今週の達成`
  2. `## 目標の振り返り`
  3. `## 気づき・学び`
  4. `## 改善したいこと`
  5. `## Focus との関係`
  6. `## 来週の一歩`
- 【参考: Coach の Goal / Focus】が空（情報なし）の場合は、`## Focus との関係` を出力せず、既存の5つの見出し（`## 今週の達成`、`## 目標の振り返り`、`## 気づき・学び`、`## 改善したいこと`、`## 来週の一歩`）だけを順番通りに使用する。
