## 抽出条件およびルール

1. **確定済み人物IDの厳格利用**:
   - `person_ids` には、入力内に存在する確定済みの人物ID（`person_id`）のみを指定してください。
   - 入力に存在しない人物IDや、未解決の名前・IDを出力してはいけません。
2. **多対多関連のサポート**:
   - 1つの出来事や関係性が複数の人物に関連する場合（例: 「AさんとBさんが共同プロジェクトを開始した」など）、`person_ids` 配列に該当するすべての人物IDを記載してください。
3. **持続情報と重要転機の優先**:
   - `fact`: 仕事、家族、学んでいる技術、使用ツール、所属など、人物に関する事実。
   - `preference`: 人物の好み、苦手なもの、対話時の希望・スタイル。
   - `pattern`: その人物の行動パターン、反応傾向、習慣。
   - `commitment`: その人物との継続的な約束、共同目標、未完了の取り決め。
   - `episode`: 単発であっても将来の対話にきわめて有用な「重要な転機・イベント」（例: 転職、結婚、引越し、大きな決断など）。
4. **根拠の厳格性**:
   - 入力ノート本文に書かれていない情報を創作・推測してはいけません。
   - `evidence` の `quote` は入力ノート内の記述を正確に引用してください。
5. **topics と tags**:
   - `topics`: 既存のトピック候補リスト: ${topic_candidates} にある項目のみを使用してください。
   - `tags`: 人物関連のキーワードや分類タグを指定してください。
6. **memory_key**:
   - 人物メモリ用の識別キー。半角英数字とハイフンのみを使い、一意で分かりやすいキー名を生成してください（例: `tanaka-job-software-engineer`, `sato-yamada-joint-project`）。
