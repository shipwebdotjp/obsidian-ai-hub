# 自動ロールバックを行わず、要約Eventと人間判断で復旧する

## Status

Accepted

## Context

Taskは既存Agent/Coding runを起動し、途中で取消・サーバー停止・失敗する。これらの外部作用を
横断して原子的に戻すことはできない。個人用途では完全な出力保存より、復旧判断に必要な要約を
30日保持する方が運用に見合う。

## Decision

- 自動ロールバックと自動再実行はしない。
- 実行中の取消は子runへ取消を伝播し、新規Stepを始めず、実施済み/未実施StepをEventに残す。
- worker所有の実行状態だけを停止時に `interrupted` とし、明示的再計画だけで再開する。
- Task Eventは追記のみ、Plan・Event・結果はterminal化から30日後に削除する。
- 全入出力やLLM非公開思考過程は保存しない。既知設定秘密値は保存前にredactする。

## Consequences

- 途中変更は残り得るため、復旧はTask詳細のEventと子runへの参照を基に人間が判断する。
- 未知の秘密値は検出できないため、自由文に含めない運用が必要になる。

## Alternatives

- スナップショット復元/git revert: 外部作用を含むため信頼できず不採用。
- 再起動時の自動再実行: 二重作用を起こし得るため不採用。
- 全文無期限保存: DB肥大化と秘密混入リスクが大きく不採用。
