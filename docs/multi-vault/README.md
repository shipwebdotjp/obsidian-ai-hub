# Multi-Vault

単一の Obsidian Vault 前提を、用途別に複数の Markdown Vault を扱える基盤へ置き換えるための設計文書群です。

| 文書 | 内容 |
| --- | --- |
| [specification.md](specification.md) | v1 の確定仕様、境界、公開契約、操作シナリオ |
| [plan.md](plan.md) | 実装フェーズと完了条件 |
| [todo.md](todo.md) | 実施順の ToDo リスト |
| [roadmap.md](roadmap.md) | v2 以降の拡張候補 |

v1 は未実装である。高コストかつ横断的な判断は、実装着手時に
`ai_wiki/10-Decisions-Architecture.md` へ ADR として記録する。
