# プランナー

**プランナー** 画面（`/planner`）は、Apple カレンダー / リマインダーの予定と、
AI が生成した提案をカレンダー上で確認・処理する画面です。
**提案が自動で Apple カレンダー / リマインダーへ書き込まれることはありません。**

## 提案を生成する

```bash
uv run -m obsidian_ai_hub --generate-planner-proposals
```

直近のノート・サマリ・予定の文脈から、カレンダー予定やリマインダーの提案を生成します。
提案は `planner_proposals` に保存され、LINE へ通知されます。

## カレンダーの見方

- **月** / **週** を切り替えられます。
- **‹** / **今日**（**今週**） / **›** で期間を移動します。
- 表示記号の目安:
  - **◐** 終日 Apple 予定
  - 時刻付き Apple 予定
  - **⏰** リマインダー
  - **🔁** 定期予定
  - **⏳** Inbox の保留
  - **✨** AI 提案（紫のチップ）
- 日付未定の提案は **日付未定のAI提案** にまとまります。

## 提案を処理する

提案を選ぶと **AI提案の編集** パネルが開きます（デスクトップのみ）。

| 操作 | 内容 |
| --- | --- |
| **保存** | 提案内容の編集を保存します。 |
| **Appleに登録** | 提案を Apple カレンダー / リマインダーへ登録します。 |
| **却下** | 却下理由（任意）を付けて却下します。 |

- 昇格すると Apple カレンダー / リマインダーに登録されます。
- 却下すると再利用のため fingerprint が解放され、理由は次回の提案生成に参考にされます。
- **AI提案を生成** ボタンからも提案を生成できます。
- Apple 連携のエラーは「Apple連携でエラーが発生しました」として表示されます。
