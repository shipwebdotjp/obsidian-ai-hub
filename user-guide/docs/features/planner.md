# プランナー

**プランナー** 画面（`/planner`）は、Apple カレンダー / リマインダーの予定と、
AI が生成した提案をカレンダー上で確認・処理する画面です。
**提案が自動で Apple カレンダー / リマインダーへ書き込まれることはありません。**

## 提案を生成する

```bash
uv run -m obsidian_ai_hub --generate-planner-proposals
```

提案の材料は、日次ノート（直近7日）に **自分で書いた用件** だけです。
活動ログ・日次/週次サマリ・プロジェクト・リサーチから作業を推測して候補を作ることはありません。
生成は毎日 06:00 に定期実行され、根拠になる用件が無い日は **0件で正常終了** します（通知も出ません）。

- 各提案は、日次ノートの根拠行を `[E1]` のような ID で引用します（`evidence.ref`）。
- 引用先を確認できない候補は保存されません。
- 引用できるのは「今日の目標」「今日のタスク」「メモ」に書かれた行です。振り返り・気づき・
  天気・移動・習慣トラッカー・Apple から書き込まれた予定/タスク、テンプレートのみのノートは対象外です。
- 生成前に、日付が過ぎた提案と作成から30日を超えた提案は `expired` になります（行と履歴は残ります）。
- 候補の日付は今日以降に限られます。過去日の候補は保存されず、日付を決められないリマインダーは日付なしになります。
- 提案は `planner_proposals` に保存され、1件以上あるときだけ LINE へ通知されます。

### 生成内容を確認する（保存しない）

```bash
uv run -m obsidian_ai_hub --planner-dry-run
```

候補と、保存されなかった理由（`ref_not_found` / `evidence_missing` / `duplicate_active` など）を
JSON で表示します。データベースは変更せず、通知もしません。

## カレンダーの見方

- **月** / **週** を切り替えられます。
- **‹** / **今日**（**今週**） / **›** で期間を移動します。
- 表示記号の目安:
  - **◐** 終日 Apple 予定
  - 時刻付き Apple 予定
  - **⏰** リマインダー
  - **🔁** 定期予定
  - **⏳** Inbox の保留
  - **✨** AI 提案（紫のチップ）
- 日付未定の提案は **日付未定のAI提案** にまとまります。

## 提案を処理する

提案を選ぶと **AI提案の編集** パネルが開きます（デスクトップのみ）。

| 操作 | 内容 |
| --- | --- |
| **変更を保存** | タイトル・日時・根拠などの編集だけを保存します。却下や削除は行いません。 |
| **Appleに登録** | 提案を Apple カレンダー / リマインダーへ登録します。 |
| **却下** | 確認ダイアログで理由（任意）とコメントを選び、**却下を確定** したときだけ却下します。 |
| **完全に削除** | 確認なしで未処理の提案を即時に物理削除します。 |

- 昇格すると Apple カレンダー / リマインダーに登録されます。
- 却下は履歴を残す操作です。fingerprint は再利用のため解放され、理由は次回の提案生成に参考にされます。
- 完全に削除は履歴・却下理由・fingerprint を残さない操作です。同じ内容が再提案されることがあり、取り消しやゴミ箱はありません。
- 完全に削除の対象は未処理（proposed）の AI 提案だけです。Apple に登録済みの予定・リマインダーには影響しません。
- **AI提案を生成** ボタンからも提案を生成できます。0件のときは「新しい提案はありませんでした」と表示されます。
- Apple 連携のエラーは「Apple連携でエラーが発生しました」として表示されます。
