# AIエージェント

**AIエージェント** 画面（`/agents`）では、汎用の AI エージェントを作成し、
セッション単位で会話できます。会話履歴と実行記録は保存されます。

## エージェントを作成・編集する

1. 左サイドバーの **＋ 新規作成** を押します。
2. **エージェント設定編集** で次を設定します。
   - 名前、システムプロンプト
   - プロバイダ / モデル
   - 詳細設定（最大トークン、reasoning effort など）
   - 利用するツール
   - 委譲先エージェント
   - プロンプトテンプレート（**テンプレートを追加** / 各テンプレートの **編集** / **削除**）
3. **保存する** を押します。

エージェントの削除は `aria-label="エージェントを削除"` の操作から行います。

## セッションで会話する

左サイドバーでセッションを作成・選択・検索できます。セッションはピン留め・タイトル編集・削除ができます。

- 入力欄の **送信** でメッセージを送ります。
- **キャンセル** で実行中の会話を中断できます。
- 画像を添付すると送信前にプレビューされます（`aria-label="送信前の添付画像"`）。
- 会話中のインライン質問（HITL）カードで、その場で回答できます。

## Vault ファイルをコンテキストに追加する

入力欄で **@** を打つか、**＋ → Vault ファイル** を選ぶと、Vault の Markdown ノートを選択できます。
選択したファイルはチップとして表示され、送信時に全文がサーバー側で読み取られて会話の文脈に含まれます。

- ファイル名・パスでの即時検索、本文での検索、ディレクトリツリーからの選択が同じ画面でできます。
- 対象は Markdown（`.md`）のみ、1メッセージあたり最大5件です。
- 参照したファイルはメッセージにもチップ表示されます。会話中は毎回 Vault から読み直すため、
  ノートを編集した後の追質問にも最新の内容が反映されます。
- 送信後にファイルが削除・移動された場合は、実行は継続し「見つかりません」と注記されます。

## ツールとスキル

- エージェントには許可するツールを選択して付与します。
- /（スラッシュ）コマンドで会話中にスキルやテンプレートのコマンドパレットを呼び出せます。
- 使用バックエンド（OpenCode ACP など）はコーディング側と共通の実行基盤を利用します。

### Vault への書き込み（`vault_write_file`）

`vault_write_file` を付与したエージェントは、`VAULT_PATH` 配下に UTF-8 テキストを直接書き込めます。

- 入力は `relative_path`（Vault からの相対パス、必須）、`content`（書き込む本文、必須）、
  `overwrite`（既存ファイルの上書き。既定 `false`）です。
- 絶対パスや `..`、Vault 外へ逃げるシンボリックリンクは拒否されます。
- 存在するファイルへの書き込みは、`overwrite` を明示的に `true` にしない限り失敗し、ファイルは変更されません。
- 存在しない親ディレクトリは自動作成され、書き込みは一時ファイル経由で原子的に行われます。

### 画像生成（`image_generate`）

`image_generate` を付与したエージェントは、プロンプトから画像を生成して保存し、
会話画面にインライン表示・ダウンロードできます。既定は低品質・小サイズです。
応答本文に `![説明](/api/v1/media/{media_id})` と書かれている画像も、その場に
インライン表示されます。
保存先やモデル、既定サイズ・品質は `config/config.yml` の `image_generation` で設定します。
詳細は [画像生成](image-generation.md) を参照してください。

:::note[送信キーの挙動]
Enter の挙動は **設定** 画面（`/settings`）の「チャット入力の送信方法」で切り替えられます。
:::

## 保存されるもの

- 会話履歴、セッション、実行記録が SQLite に保存されます。
- セッションごとのプロンプト下書きはブラウザの sessionStorage に保存されます（秘密情報は保存されません）。
- Webチャットの会話は、週次処理で[長期メモリ](memory.md)の候補抽出元になります。候補になるのはユーザー自身の発話だけで、
  エージェントの返答は候補になりません（根拠の検証で保証されます）。Task Agent・ワークフローのセッションは対象外です。
