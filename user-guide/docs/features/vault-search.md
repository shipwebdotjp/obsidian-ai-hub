# Vault 検索

**Vault 検索** 画面（`/vault-search`）では、インデックス化された Vault を
意味検索・キーワード検索・ハイブリッド検索できます。また、**ファイル
エクスプローラー** タブで Vault の Markdown をディレクトリから辿って閲覧できます。

画面上部のタブで **検索** と **ファイルエクスプローラー** を切り替えます。
選択したノートは共通のビューアー（本文・frontmatter・Markdown 表示・
**Obsidian で開く**）で開きます。

## 検索する

1. **検索クエリ** を入力します（Enter でも検索できます）。
2. モードを選びます。
   - **Hybrid**（既定）
   - **Keyword**
   - **Similarity**
3. 件数を選びます（**5件** / **10件** / **20件** / **50件**）。
4. **検索** を押します。

## 検索履歴

**最近の検索** に直近の検索（最大 20 件）が保存され、再実行できます。
各項目には `mode / N件` が表示されます。履歴はブラウザの localStorage に保存されます。

## 結果を見る

一覧から結果を選ぶと **検索結果プレビュー** パネルが開きます。
検索結果が見つからない場合は「検索結果が見つかりませんでした」と表示されます。

## ファイルエクスプローラー

**ファイルエクスプローラー** タブでは、ディレクトリツリー・ファイル一覧・
ビューアーを並べて Vault の Markdown を閲覧できます。

- ルートを選ぶと直下の Markdown、ディレクトリを選ぶとその配下の Markdown を
  再帰的に一覧表示します。
- 一覧のファイルを選ぶとビューアーに本文が表示され、**Obsidian で開く** から
  デスクトップの Obsidian で開けます。
- ファイル一覧はタブを初めて開いたときと **再読込** のときにだけ取得します。

## 絞り込みと並べ替え

- **ファイル名で絞り込み** はファイル名の部分一致（大文字小文字を区別しない）
  で一覧を絞ります。ディレクトリ名は対象外です。絞り込みはタブを切り替えても
  維持されますが、ページを再読込すると空に戻ります。
- 一覧ヘッダーの **ファイル名** / **更新日時** で並べ替えます。同じ列をもう一度
  押すと昇順・降順が切り替わります。初期値は更新日時の新しい順です。

## 状態の復元

最後に開いていたタブ、エクスプローラーの展開済みディレクトリ・選択ディレクトリ、
表示していたノート、並べ替えの列と方向はブラウザの localStorage に保存され、
次回同じ画面を開いたときに復元されます。本文・検索結果・絞り込み文字列は保存
しません。削除・移動済みのディレクトリやノートは該当する状態だけが初期値に戻り、
一覧やビューアーはそのまま利用できます。

## インデックスの更新

検索対象を最新にするには、Vault の同期を行います。

```bash
uv run -m obsidian_ai_hub --sync-vault
```

インデックスを完全に再構築する場合:

```bash
uv run -m obsidian_ai_hub --rebuild-vault
```

インデックスの保存先と埋め込みモデルは `config/config.yml` の `vault_index` で設定します。

## CLI から検索する

```bash
uv run -m obsidian_ai_hub --vault-search --query "project planning" \
  --k 5 --search-mode hybrid --json
```

`--k` は結果件数（既定 10）、`--search-mode` は `similarity` / `keyword` / `hybrid`（既定 hybrid）、
`--json` は機械可読の JSON 出力です。
