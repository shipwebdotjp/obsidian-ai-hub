# 人物管理

**人物管理** 画面（`/people`）は、サマリから抽出された人物の解決・重複統合・
Vault ファイルとの同期を管理します。

ヘッダーの **データを再読み込み** で最新状態を取得できます。

## タブ

| タブ | 内容 |
| --- | --- |
| **未解決候補** | サマリから抽出された未解決の人物候補を、既存人物への紐付け・新規作成・却下で解決する。 |
| **却下済み候補** | 却下した候補を再オープンする。 |
| **人物一覧** | 表示名・別名の編集、本人（principal）設定、削除、マージ。 |
| **属性定義** | 人物属性の定義を作成・更新・削除する。 |
| **関係タイプ** | 人物間の関係タイプを作成・更新する。 |
| **重複候補** | 重複グループを確認し、マージプレビューから統合する。 |
| **Vault入力レポート** | Vault との同期結果を確認し、**同期** を実行する。 |

人物の関係は根拠（証拠）付きで作成・更新・削除できます。
同じ関係を作成しようとした場合は、既存への統合が通知されます。

## 注意点

- **本人（principal）に設定した人物は削除できません。** 本人設定を解除してから削除してください。
- 名前・別名の競合は `409` を返し、マージ先の候補が提示されます。
- 削除は専用の確認ダイアログを経由します。

## CLI からの同期

未解決の人物候補や重複した `people` 行を、Vault の人物ノート（`aliases` メタデータ）に対応する
正規レコードへ統合します。

```bash
uv run -m obsidian_ai_hub --sync-people
```
