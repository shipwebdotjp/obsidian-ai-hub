# 定期記録

**定期記録** 画面では、散髪・オイル交換・脱毛など、定期的に行う行為の実績を
記録し、次回予定日と期限通知で管理できます。シリーズ（追跡対象）を作成し、
実行のたびに記録を追加します。

## シリーズを作成する

1. **＋ シリーズ作成** を押します。
2. イベントタイプ・推奨間隔・開始実績（最初の実行日・メモ・写真・初期通算回数）を
   入力して **作成** を押します。
3. 一覧カードに最新実行日・経過日数・通算回数・次回予定日が表示されます。

## 記録を追加・編集する

- カードの **詳細・履歴を見る** から、**新しい記録を追加** で実行日・メモ・写真を
  登録します。
- 履歴の **編集** で実行日・メモ・写真・回数寄与を変更できます。
  **削除** で記録を消せます（最後の記録を消すとシリーズ自体も削除されます）。

## 写真の形式と添付方法

- 対応形式は JPEG・PNG・GIF・WebP と、iPhone の **HEIC / HEIF** です。
- HEIC / HEIF はサーバー側で JPEG（品質 90）に変換して保存します。元の HEIC は
  残りません。Live Photo は主静止画だけを保存します。
- 撮影日時・位置情報などの EXIF は維持されます。向き情報はピクセルに反映した
  うえで整合させるため、他アプリで開いても向きが崩れません。
- 写真欄はファイル選択のほか、画像ファイルの **ドラッグ＆ドロップ**（1枚まで）
  に対応しています。複数ファイルをドロップした場合は選択が変わらず、欄内に
  エラーが表示されます。
- 形式の最終判定はサーバー側のバイト列検証です。壊れた画像や未対応形式は
  エラーになり、保存されません。
- 既存写真がある記録は、解除しなくても新しい写真の選択・ドロップで置換できます。
  **写真を解除する** で写真なしにもできます。
- 写真はメディアライブラリに共有保存されます。実行記録から参照されている
  メディアは削除できません。

## 日付の表示

- 画面の日付は `2026/10/06(火)` のように曜日付きで表示されます。
- 入力欄はカレンダー形式のままです。次回予定日は最新実行日に推奨間隔を加えて
  自動計算されます（月加算で同日がない月は月末に丸めます）。
- 次回予定日が近づくとカードにバッジ（期限超過・本日期限・次回予定）が表示され、
  期限日にはリマインダーが一度だけ通知されます。

## 関連する機能

- 生成・編集した画像の保存先は [画像生成](image-generation.md) と共通の
  メディアライブラリです。
