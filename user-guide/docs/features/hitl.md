# 確認待ち（HITL）

**確認待ち** 画面（`/hitl`）は、人間の承認・回答を待っているタスク（HITL Run）を処理する場所です。
サイドバーの **確認待ち** には未処理件数のバッジが表示されます。

## 一覧

- フィルター: **すべて** / **回答待ち** / **再開可能** / **実行中** / **完了** / **失敗** / **キャンセル済み**（既定は回答待ち）。
- 表示種別バッジ: **ASK**（会話内の質問）、**日次人物変更候補** など。
- 1 ページ 50 件。

## 質問に回答する

質問カードの **質問** セクションで回答します。

- 種別に応じた入力: 真偽（**はい (True)** / **いいえ (False)**）、選択（カードまたは選択ボタン）、自由記述（**回答を入力してください…**）。
- 必須の質問には **必須** バッジが付きます。
- 任意の **コメント（任意）** を添えられます。
- **回答を送信** で回答します。

送信成功時は「回答を正常に送信しました。」と表示されます。

:::warning[コメントが必須の場合]
メモリメンテナンスのフィードバックで「再提案」を選ぶ場合は、コメントの入力が必須です。
:::

## 特殊な確認内容

HITL には、内容に応じた読み取り専用の詳細ブロックが表示されます。

| 種類 | 表示される内容 |
| --- | --- |
| 長期メモリ候補のメンテナンス | **提案アクション**、**根拠・理由**、変更後の本文、対象メモリ（**正本 (残す)** / **吸収 (superseded)** / **失効対象**） |
| リサーチテーマ提案 | **提案内容**、テーマ、**調査の方向**、**今調べる理由** |
| カレンダー登録提案 | タイトル、開始、終了、場所、**元の内容** |
| リマインダー登録提案 | タイトル、期限、**元の内容** |
| 人物候補 | 属性・関係の作成 / 更新 / 削除の Before / After、**引用（根拠テキスト）**、**抽出理由** |

## 実行全体をキャンセルする

回答待ち・再開可能なタスクでは **実行全体をキャンセル** を選べます。
確認後、その実行全体がキャンセルされます。

## CLI

HITL を 1 回スキャンして処理します。手動の復旧・トラブルシューティング用です。

```bash
uv run -m obsidian_ai_hub --hitl-dispatch
```

常駐ワーカーとしてループ実行します（LaunchAgent が利用）。

```bash
uv run -m obsidian_ai_hub --hitl-worker
```

:::note
常駐ワーカーを動かしている間は、`--hitl-dispatch` を定期ジョブで有効化しないでください。
:::
