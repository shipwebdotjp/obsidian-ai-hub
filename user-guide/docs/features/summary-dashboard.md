# サマリダッシュボード

**サマリダッシュボード** 画面（`/summary-dashboard`）では、生成済みの日次・週次・月次サマリを
閲覧・編集・再生成できます。タブは **ホーム** / **一覧** / **統計** です。

## ホーム

3 つのカードを表示します。

- **今月の月次サマリ**
- **最新の週次サマリ**
- **昨日の日次サマリ**

生成済みなら **詳細**、未生成なら「月次未生成」などの表示になります。

## 一覧

期間ごとにサマリを閲覧します。

| 操作 | 内容 |
| --- | --- |
| **再生成** | 現在のサマリを新しい生成結果で上書きします（手編集も含む）。 |
| **編集** | サマリの項目（要約・キーワード・気分・睡眠・項目・トピック・人物・プロジェクトメモ）を編集して **保存**。 |
| **削除** | サマリを削除します。 |

未生成の期間は「未生成の日次/週次/月次サマリ」として **作成** できます。

:::warning[上書き・削除は取り消せません]
**再生成** は手編集した内容も含めて新しい生成結果で上書きします。
**削除** は取り消せません。必要な内容は事前に退避してください。
:::

## 統計

**集計期間:** のプリセット（**7日間** / **30日間** / **90日間** / **今年** / **期間指定**）を選び、
必要に応じて日付を指定して **適用** します。トピックやキーワードが集計・可視化されます。

## 生成コマンドとの関係

サマリは次の CLI からも生成できます。

- [日次・週次・月次サマリ](../daily/summaries.md) — `--summerize-day` / `--summerize-week` / `--summerize-month`
- 週次レビュー下書き — `--review-draft`
