# プロジェクト管理

**プロジェクト管理** 画面（`/projects`）は、ゴールや終了状態を持つ取り組みを
プロジェクトとして管理し、サマリと紐付けます。

ヘッダーの **新規登録** でプロジェクトを作成し、**再読み込み** で最新状態を取得できます。

## タブ

| タブ | 内容 |
| --- | --- |
| **候補受信箱** | サマリから抽出されたプロジェクト候補を解決する。 |
| **プロジェクト一覧** | ステータス・ドメインで絞り込み、選択して編集する。 |
| **履歴・却下済み候補** | 却下した候補を再オープンする。 |

## 候補を解決する

候補を選び、次のいずれかで解決します。

- **approve_new** — 新しいプロジェクトとして作成する。
- **link_existing** — 既存プロジェクトへ紐付ける（対象の選択が必須）。

却下や再オープンもできます。

## プロジェクトの項目

- `display_name`、`domain`（既定 `personal`）
- `status`（作成時は `inquiry`、候補解決時は `active` が既定）
- `goal`、`description`、`keywords`
- `start_date`、`target_date`、`completed_date`
- `project_path`、`reference_url`

:::note[名前の重複]
同一名のプロジェクトを作成しようとすると `409` になり、競合が通知されます。
:::
